## dsl-crud

Desktop-only app to generally manage DSL notes, implemented via flask.
Application Name: `dsl`, ✍️

## dsl-graph

Relationship view, desktop only.
Formerly called "graphirst".

`graph`, 🪢

## dsl-mobile

Contains multiple Flutter-based, mobile optimized apps to interact with the notes.

### calendar

read-only display of dated events.
`calendar`, 📆

### note

CRUD operations on all notes, kind of like `dsl-crud` but workable on mobile, 
a bit simpler but with more convenience options.

`note`, 📝

### queue

Read-only queue view, for inspiration.

`queue`, 🎲
